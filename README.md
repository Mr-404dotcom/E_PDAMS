**E-PDAMS (Electronic Prefect Disciplinary Action Management System)** is a web-based system designed to help schools efficiently manage and monitor student disciplinary records and related administrative processes. The system centralizes student violation records, disciplinary actions, schedules, sanctions, behavioral monitoring, parent notifications, and clearance information in one platform. It aims to reduce manual record-keeping, improve data organization and accessibility, and provide authorized school personnel with a more efficient way to track and manage disciplinary cases. By using a centralized digital system, E-PDAMS helps improve the accuracy, consistency, and efficiency of disciplinary management while supporting better monitoring of student behavior and administrative decision-making.
